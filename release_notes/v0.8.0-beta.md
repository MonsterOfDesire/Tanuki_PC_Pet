# Tanuki PC Pet v0.8.0-beta

## 玩家有感更新

- 新增自主合奏：角色可發起演奏，其他角色會無視、觀看或加入；支援多人延長演奏、忙碌後重新判定、拖曳／隱藏個別退出、睡眠角色被音樂喚醒，以及自然完成後的心情與關係收益。
- 新增沙盒／黃金傳說分離的成就系統與獎盃蒐集櫃；競賽、合奏、睡眠、變身、照護、蜂蜜保護、分享食物、工作及稀有鶴寶站立均有 canonical gameplay event 來源。
- 資訊中心、事件日誌、家庭摘要、狀態設定、飲食餐盤、成就介面與更新流程提供繁體中文、簡體中文、日文及英文；角色 runtime key 與存檔仍維持穩定的英文 canonical name。
- 新增獨立 `TanukiUpdater.exe` 與可攜版更新包規格；使用者可保留設定、家庭資料及成就，直接由舊版資料夾更新，不必解除安裝。
- 情緒氣候改為以自然變動頻率、正負傾向與幅度形成明朗／均衡／多彩差異；均衡模式納入睡眠、合奏與陪伴效果校準，睡眠及合奏不再無上限堆高心情。

## 穩定性與體驗修正

- 一般 random 動畫、短點反應與奶瓶照護 approach 現在會在符合 manifest context、band 與 mood tag 的完整候選池中依 weight 抽選，不再固定偏向第一個 mood。
- 修正競賽向左跑後相對位置顛倒、落後者倒退跑、成人終點重疊、飛行返抵工作列前誤收邀請，以及跑道兩人的實際距離不易驗證等問題。
- 修正睡眠中的蜂蜜保護者卡在拿走蜂蜜、合奏只因特定小孩中斷、鶴寶站立成就在動畫真正顯示前誤解鎖，以及資訊中心最小化／移出螢幕後無法叫回。
- 改善資訊中心首次開啟與角色關係頁切換效能，使用延遲建立、素材快取與 presentation 未變時原地略過刷新。
- 完成四語事件句型、舊事件顯示相容、狀態設定 responsive 版面，以及簡中變身狀態參數契約修正。

## 架構與開發工具

- 完成 `app_runtime.py` 分層收斂：入口保留組裝、shutdown 與角色查找，Activity、變身、供品、household、achievement、persistence 與 UI 相容入口分由窄介面的 controller／adapter 管理。
- 建立可重現的 mood Monte Carlo 校準工具，直接使用正式睡眠／合奏排程常數並輸出 band 分布、首次進入時間、Activity 暫停與收益貢獻。
- 更新器加入 release 資產一致性驗證、原生進度視窗、舊 runtime／下載檔清理、單一 backup 保留，以及不連網的 `--self-check` 成品測試。

## 相容性

- config schema 升至 8；schema 1–7 會依序遷移，新增 `ui_locale` 預設為繁體中文。
- manifest schema 維持 1；所有新增動畫流程仍由 manifest context／band 管理，不以程式碼指定 GIF 或 action。
- `v0.7.0-beta` 的 `config.json`、household、成就與角色位置資料由更新器保留。
