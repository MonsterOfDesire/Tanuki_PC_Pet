# Tanuki PC Pet v0.6.0-beta

## 玩家有感更新

- 以人工設計素材重建飲食餐盤與狸貓資訊中心。
- 將角色關係與召喚、事件日誌、家庭摘要及狀態設定整合為可換頁資訊中心。
- 支援資訊中心自由縮放、建議尺寸、焦點裁切與頁面分離。
- 新增具有展開、收合、釘選及狀態摘要的側邊啟動器。
- 角色關係、事件、家庭、設定與餐盤採用各自的識別色。
- UI 角色名稱改用繁體中文顯示，並保留後續多語系切換基礎。

## 穩定性與體驗修正

- 記住資訊中心位置、尺寸、最後分頁與建議尺寸。
- 更換螢幕或 DPI 後會將視窗限制回目前可用桌面範圍。
- 所有視窗改用一致的自訂外框、淡化捲軸與 DPI／bitmap scaling 規則。
- 啟動素材缺失時顯示明確錯誤並以非零代碼結束。

## 架構與開發工具

- 新增 `UiSkinAssets`、`SkinnedWindowFrame`、集中式 theme token 與共用視窗 chrome。
- UI 維持 presenter、controller、actions、binding 與 state mapper 邊界。
- 可攜打包納入全部 UI 素材及角色頭像。
- 新增 Windows CI，執行完整測試、五角色 manifest dry-run 與打包輸入檢查。
- 將共享食物分層測試工具與公開文件改為 clone 後可直接使用的相對路徑。
