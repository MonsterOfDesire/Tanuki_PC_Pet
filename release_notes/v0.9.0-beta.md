# Tanuki PC Pet v0.9.0-beta（草案）

## 主要更新

- 新安裝、缺少 `world_mode` 或世界模式值無效時，預設進入沙盒；已保存黃金傳說的既有使用者維持原設定。
- 新增 macOS 13 以上功能受限版，分別提供 Apple Silicon (`arm64`) 與 Intel (`x64`) 套件；角色、Activity、四語 UI、事件、成就及存檔與 Windows 共用核心。
- 建立平台能力層；macOS 明確停用 Win32 視窗偵測、視窗停棲／視窗間飛行、全域滑鼠監聽與 Windows 獨立更新器，不以執行期例外碰運氣。
- macOS 設定、家庭狀態與成就存入 `~/Library/Application Support/Tanuki_PC_Pet/config.json`，不寫入唯讀 `.app` bundle。
- macOS 狀態設定仍可手動檢查新版本，但只會開啟 Release 下載對應套件，不會誤用 `TanukiUpdater.exe`。
- macOS 角色使用逐幀 alpha 原生輸入遮罩及 non-activating panel，透明區域可穿透到其他應用程式，點擊角色不會把資訊中心帶到前景；角色與收合控制列會顯示於所有 Spaces。
- 雙螢幕熱插拔、解析度及工作區變更會重新定位最左側收合入口與地面角色；macOS 不再建立可能錯位放大的灰綠 `SensorZone`，改為保留可點擊的窄收合入口。

## 建置與驗證

- 新增可重現的 iconset／`.icns` 產生工具、PyInstaller `.app` spec、Info.plist、ad-hoc 簽章驗證及架構別 ZIP 建置腳本。
- GitHub Actions 使用 `macos-26` 與 `macos-26-intel`，執行完整測試、manifest 驗證、兩種架構建置、簽章檢查及真正 Cocoa backend 的三秒 packaged smoke test。
- 修正 Qt Tool window 預設 `MoveToActiveSpace` 與 AppKit `CanJoinAllSpaces` 互斥而造成程式在首個角色建立時無視窗退出；原生視窗增強另加入失敗降級，不能再阻止主程式啟動。
- Windows 舊功能仍由原 Windows CI、完整測試及 build input check 覆蓋。

## 已知限制

- macOS 版不會停在其他應用程式視窗上，也不執行依賴全域游標感知的互動；角色仍可在可用桌面地面移動並接受自身視窗上的點擊及拖曳。
- 首批 CI 產物只有 ad-hoc 簽章，沒有 Apple Developer ID 簽章或 notarization；Gatekeeper 可能要求使用者手動確認來源。
- macOS 暫不提供原地更新，使用者需從同一 Release 下載新 `.app` 並手動替換。

## Release 資產規劃

- Windows：新版可攜 ZIP、`TanukiUpdater.exe`、`tanuki-update.json`、checksums 與 SBOM。
- macOS：`TanukiPet-0.9.0-beta-macos-arm64.zip`、`TanukiPet-0.9.0-beta-macos-x64.zip`。
- 不在 macOS ZIP 內重複放入 Windows 主程式或更新器。
