# Tanuki PC Pet v0.7.0-beta

## 玩家有感更新

- 新增五名角色的自主睡眠，以及觀察睡眠者、靠近並加入睡眠群的社交入睡流程；照護型大人可因鶴寶 distress 提前醒來。
- 新增帝寶與魯道夫的自主變身、白化換圖過場與安全解除；沙盒保留形態控制，變身形態依各自能力限制參與照護、飛行、飲食、工作與睡眠。
- 新增完整賽跑 Activity：挑戰、考慮、接受／拒絕、前往起點、預備、跑步、勝負與恢復均由 manifest context 選圖。普通帝寶、天狼星、普通／變身魯道夫可自主參賽，變身帝寶不參賽。
- 競賽事件會記錄挑戰者、對手、距離、方向、實際用時與贏家；正式戰績與整體勝率會持久化並顯示於角色關係頁。
- 新增魯道夫工作 Activity：黃金傳說完成工作後增加生活費、降低家庭壓力並扣除魯道夫心情；沙盒可預覽完整動畫但不結算。
- 狀態設定新增競賽頻率與情緒氣候；家庭摘要可查看競賽倒數、睡意，以及帝寶／魯道夫的變身冷卻或剩餘時間。

## 穩定性與體驗修正

- 短點角色不再閃過拖曳動畫；按住並移動才會進入 drag，短點睡眠者會走正常 waking 流程。
- `hard_landing` 嚴格使用對應 context，不再隨機抽取其他負面表情。
- 修正競賽角色拖離、隱藏或消失後另一人卡死，以及起跑重疊、朝向跳轉、前往起點固定逾時與終點原地跑步等問題。
- 競賽速度改用小數餘數累積，畫面維持相鄰整數步進，實際抵達順序、用時與戰績一致。
- 奶瓶持有者找不到可餵食的鶴寶達 2.5 個模擬秒後會自動放回，避免角色無限占用。
- 修正變身帝寶進入陪伴照護後仍停在靠近動畫的問題。
- 家庭摘要每秒更新改為原地刷新現有元件，不再重建角色卡片與事件表，降低閃動與 runtime 卡頓。
- 狀態設定改為寬版非對稱雙欄、窄版單欄捲動配置，保留原本按鈕大小與背景。

## 架構與開發工具

- 建立通用 Activity state／rules／coordinator／runtime adapter，以及獨立的 sleep、transformation、race 與 Rudolf work executors。
- 所有新增動畫流程依 manifest context 與 band resolver 選取；程式碼不指定特定 GIF 或 action。
- manifest context 目錄擴充至 83 個 contexts，並以測試防止文件與 converter 清單漂移。
- 沙盒支援自主變身與自主競賽，同時保留無事件、無戰績、無數值結算的工作／變身／競賽開發控制。
- config schema 升級至 6，新增競賽頻率與情緒氣候 migration；household persistence 新增競賽戰績。

## 相容性

- schema 1–5 的既有 config 會自動升級至 schema 6；新增設定預設為普通競賽頻率與明朗情緒氣候。
- 舊 household 資料缺少競賽戰績時會以空資料載入，無須手動轉換。
- manifest schema 維持 1；`manifest_edit.xlsx` 仍是素材分類來源，JSON 由正式 converter 產生。
