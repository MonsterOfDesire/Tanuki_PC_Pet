# Tanuki PC Pet v0.11.0-beta

本版為跨平台測試版，Windows 與 macOS 使用同一份來源版本。

## 主要更新

- 狀態設定改為木製公告板介面，分為「模式設定」與「開發工具」；競賽、合奏可停用，自主睡眠及自主變身可獨立開關。停用不會強制中止正在進行的活動。
- 新增全介面文字尺寸小／中／大（80%／100%／150%），首次使用預設中。四語說明、窄版捲動、卡片及導覽按鈕同步適應文字尺寸。
- 資訊中心、事件、家庭摘要、獎盃、回憶相簿與周邊控制採用一致的按鈕與表面樣式；補回狀態設定懸停說明，不搶走其他視窗焦點。
- 側邊相機在相簿滿載時持續顯示警告且可點選查看原因；不開啟擷取、不自動刪除照片。
- 家庭成員橫列支援滑鼠滾輪與觸控板捲動，不必拖曳底部橫條。

## 角色互動修正

- 修正平滑拖曳在螢幕交界被夾回原螢幕的問題，包含並排、上下錯位及中間有空白的螢幕配置。
- 鶴寶喝奶統一維持 8 個模擬秒，包含玩家直接給奶瓶與奶瓶照護。
- 蜂蜜攔截後，大人停留 5 個模擬秒；鶴寶第 2 秒起可自由活動，同時保留至第 5 秒的負面心情餘波。不追加心情扣分或重複事件。
- 直接供品資格與具體動畫由 manifest 的 context、band、weight 決定，不再由舊 action 白名單先排除適合的素材。天狼星可在素材允許的 normal band 邊走邊喝蜂蜜。
- 修正睡眠靠近的長時間互相阻擋，以及競賽收尾中魯道夫左側躺姿的篩選與動畫沿用問題。
- 修正首次開啟狀態設定時資訊中心圖層下沉閃爍，並調整側邊欄長文字語系的寬度。

## macOS

- 補齊回憶相簿背景與前景素材的打包，避免進入回憶相機頁面時因缺少素材而退出。
- App 圖示使用控制列角色圖與高對比底板；提供 Apple Silicon（arm64）及 Intel（x64）兩份套件。
- macOS 版仍不提供其他視窗停棲、Windows 全域游標偵測及 Windows 獨立更新器。下載新版後手動替換 `.app`，存檔留在 Application Support。
- 套件只有 ad-hoc 簽章，尚無 Apple Developer ID／notarization。實機多螢幕、Spaces、螢幕錄製權限仍需測試者驗證。

## 相容性與發布資產

- config schema 升至 12；舊設定自動遷移，不需要刪除設定、成就或照片。
- Windows：完整可攜資料夾 ZIP、`TanukiUpdater.exe`、`tanuki-update.json`、SHA-256 與 SBOM。
- macOS：`TanukiPet-0.11.0-beta-macos-arm64.zip`、`TanukiPet-0.11.0-beta-macos-x64.zip`。
- Windows EXE 簽署後才生成最終 ZIP、更新 manifest 與雜湊；GitHub tag／Release 建立及發布由維護者另行執行。
