## 一、結論先行

## 二、調查要回答的問題

我們把問題分成三層，避免互相混淆：

1. **素材是否同源**：兩張 GIF 是否共用身體、姿勢、動作、影格或後期差分。
2. **作者是誰**：誰畫了共同構圖、像素圖、角色版本、動畫、表情或後期修改。
3. **作者允許什麼**：是否允許影片使用、修改裁切、App 內顯示、Repository 保存原檔、Release／安裝包再散布、營利用途，以及是否要求署名或事前聯絡。

只有同源並不能證明作者；確認作者也不能自動證明獲得利用許可。

## 五、如何判斷「沒有找到禁止轉載標示」

本調查採用下列最低要求：

1. 優先檢查可識別作者的第一方簡介與原始貼文。
2. 使用日文常見限制詞進行帳號內搜尋。
3. 若作者有官網、Bluesky 或其他第一方頁面，進行交叉核對。
4. 分開記錄「明示禁止」「沒有找到條款」「僅提供下載」「作者匿名」等狀態。
5. 不把社群默認、公開下載、影片使用或作者未提出異議解讀成授權。
6. 不把素材包整理者、轉載影片上傳者或 Git 匯入者當成原作者。
7. 同串別人的取用邀請、作者對使用範例的友善回應及軟體製作資訊，都不代替對特定用途的明確許可。
8. 記錄實際查過的日期、資料入口與未覆蓋範圍；搜尋未命中、頁面失效、HTTP 403 或分類缺漏不算「作者沒有禁止」。

因此，下列表述才是準確的：

> 在截至指定日期所檢查的公開第一方頁面、已知貼文、搜尋詞及存檔範圍內，沒有找到某位作者的禁止轉載標示。

不應寫成：

> 已確認作者沒有禁止轉載，或素材可以自由使用。

前者是有範圍和日期的調查結果；後者則是目前證據不能支持的法律或授權結論。

## 六、用途別權利矩陣

即使沒有找到明示禁止，每一種用途仍需分別確認：

| 用途 | 目前狀態 |
|---|---|
| 影片或直播中使用 | 多數作者未知或條款未確認 |
| 修改、裁切或製作差分 | 未建立完整許可 |
| App 內嵌顯示 | 未建立許可 |
| 公開 Repository 保存原始 GIF | 未建立許可 |
| Release／安裝包再散布 | 未建立許可 |
| 商業或營利用途 | 未確認，且另受上游 IP 規範限制 |
| 署名要求 | 多數未知 |
| 聯絡要求 | 對可識別作者應取得明確答覆 |

《賽馬娘 Pretty Derby》官方二次創作指南要求避免侵害第三方權利，並限制超出同人活動範圍的商業利用。該指南不會替個別像素或動畫作者授予原始檔再散布權。[官方二次創作指南](https://umamusume.jp/derivativework_guidelines)

## 七、目前的發布決策

本專案採用以下顏色：

- **綠色**：已有明確涵蓋預定用途的許可。
- **黃色**：作者已知，但許可僅涵蓋部分用途或仍需詢問。
- **橙色**：作者鏈不完整、匿名、多層改作、來源中斷或未取得再散布許可。
- **紅色**：已確認命中明示禁止的作者、收到拒絕或有明確移除要求。
- **灰色**：尚未調查完成；不能當作綠色。
