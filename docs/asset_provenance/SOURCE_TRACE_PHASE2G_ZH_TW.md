## 一、找到什麼原帖

[2022-01-19 原帖](https://tsumanne.net/si/data/2022/01/19/7810014/)的開串時間是 23:00:22，原始貼文編號 `888566300`。開串者以第一人稱說，當天做了會長差分、不同角色的無臉差分及表情零件，另提供當日 ZIP 與歷年合集，並宣布暫停每日投稿。這與前輪影片年表分析（本機研究資料，未公開：`docs/asset_provenance/video_analysis/sm44817709/NICONICO_COMMENTS_REVIEW_ZH_TW.md`）的 2022-01-19 那一筆相符。

同串開串者後續補上兩個 GIF，也說工作穩定後還會找適當時機製作。因此這裡確認的是「暫停每日發布」，不是永久停止創作；不能僅靠後來的「引退」彈幕取代原話。

身份識別只限同一串中相同的公開 ID，沒有把它當成跨日期固定帳號。也沒有證明這位開串者就是 Bilibili 所稱的「拉麵佬」、デオン、天美トシヒ或影片上傳者「もん」。

原帖其他板友也發布自己的素材與影片；本輪只把開串者直接提供的附件歸入該候選來源，沒有把整串附件全部算成同一人的作品。

## 三、比對方法與結果的邊界

本輪做的是可重現的精確比對：

1. 解碼外部與本地 GIF 的每個影格。
2. 依每影格透明度邊界去除留白；將完全透明像素的隱藏 RGB 歸零。
3. 對尺寸及完整 RGBA 像素計算 SHA-256，尋找相同影格。
4. 比對整段影格序列，允許循環動畫從不同起始影格開始，並另記錄播放時間是否相同。

**沒有使用縮放、鏡像、調色、感知相似度或局部構件來宣稱精確命中。** 所以本輪的 0 命中，只表示這 8 張 GIF 未在上述精確條件下對上本地檔案；不能排除重畫表情、重新量化色盤、縮放或頭身組合後的衍生關係，也不能排除未取得的合集含有本地來源。

實際逐檔及逐影格結果：比對 JSON（本機研究資料，未公開：`docs/asset_provenance/timeline_trace_20261004/gif_comparison.json`）。人工檢視用回收影格接觸表（本機研究資料，未公開：`docs/asset_provenance/timeline_trace_20261004/recovered_op_frames.png`）只顯示每附件前 8 格；機器比對使用全部 64 格。

另取得一張 2021-09-11、同樣出現在 `SOZAIYA` 分類的 PNG，額外對全套本地影格比對亦無命中。人工核對後發現是「煉獄ちゃん」插畫，不是年表的成田白仁素材，已明列為誤命中，沒有建立作者關係。
