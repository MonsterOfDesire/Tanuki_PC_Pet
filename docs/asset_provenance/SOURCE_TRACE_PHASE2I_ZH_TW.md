## 結果

2022-01-19 原帖有重要資訊：它同時包含開串者的製作自述、休止說明、其他改作者的自述、其他素材／影片合集，以及桌面程式的使用背景。**這不是單一作者發布的整串作品集。**

本輪重新核對全串 503 個貼文區塊，整理 18 則與來源鏈相關的發言，並回收另一位匿名改作者提供的雨衣差分 GIF。該圖有 8 個影格；與本地 456 張 GIF 及 1 月合集比較，沒有位元組相同的合集成員，也沒有精確 RGBA 影格／序列命中。沒有新增本地素材的作者歸名或授權。

較晚的シリウスシンボリ決勝服、鶴丸素材仍未取得可驗證的原帖或同一作者合集。已保存實際搜尋、分類索引限制及候選線索，沒有把搜尋無結果當成作品不存在。

## 二、哪些 ZIP 容易被誤認

- `4048846.zip`：開串者提供的歷年 GIF 合集；已取得並驗證。
- `4048848.zip`：另一位參與者提供致意影片的高畫質版，**不是**較晚 GIF 合集。
- `FLASH_0325.zip`：另一人聲稱自製的素材合集；原串只有檔名，未復原可驗證的下載網址。
- `FLASH_0322.zip`、`MATOME_2021_0333.zip` 等：其他影片製作者的作品／續作；不能只看 ZIP、副檔名或上傳倉庫就當成素材原作者合集。

這一區分改變了後續搜尋：合集內容、貼文的第一人稱描述及附件都要核對，不能把同串的所有 ZIP 併入同一作者。

## 四、較晚合集的追查結果與限制

優先目標仍是影片年表的三個事件：2022-05-20 的シリウスシンボリ決勝服、2022-07-29 的鶴丸及幼年版、2022-09-09 的頭身組裝套件。這些日期是先前人工核對影片的回顧自述，**尚未由各日原帖獨立確認**。

本輪以角色名、日期不同格式、GIF／素材／合集、求稱讚語句及 Axfc 為搜尋組合，另查 tsumanne 分類入口。沒有找到可驗證的較晚開串者合集。查不到不能否定影片日期，也不能排除刪除、未存檔、未收錄或標題不同。

分類查詢 `indexes.php?w=...` 搜尋的是分類名稱，不是所有串的全文。求稱讚關鍵詞沒有同名分類；ツルマル等查詢重導首頁，雖回應 HTTP 200，也不能記為全文查無結果。現存分類分頁只呈現部分年份，並非完整逐日索引。

另外抽查 [2026-10-03 的定時串](https://tsumanne.net/si/data/2026/10/03/10872131/)，解析到 12 則發言，沒有取得較晚合集連結；它不是目標日期原帖，也沒有證明開串者與 2022 年為同一人。

新增候選是[另一個公開 uploader 的歷史清單](https://uu.getuploader.com/20230612/index/date/desc/2)：搜尋服務保存的頁面列出 2023-06-14 的 `たぬきまとめ１.zip`，描述為未放到 Nico Seiga 的素材。**這只是未驗證的新線索**：當前兩頁直接讀取皆為 HTTP 403，未下載、未繞過限制；沒有確認包含本專案角色，更沒有連到 1 月開串者。不能稱為本次已找到的後續作者合集。

搜尋觀測：代表性實際查詢與候選（本機研究資料，未公開：`docs/asset_provenance/later_archive_trace_20261004/search_query_log.json`）、公開讀取回執（本機研究資料，未公開：`docs/asset_provenance/later_archive_trace_20261004/public_fetch_observations.json`）。

- 關係圖現在為 811 個節點、1,966 條關係；沒有新的本地素材作者連線、匿名身分合併或授權升級。
- 本地 456 張 GIF 雜湊未變，發布決策仍全部為橙色。
- 原有關係圖項目與來源發現逐項保留。清冊、作者政策及發布決策 JSON 本輪位元組未變；沒有修改 App、manifest、ZIP、影片、彈幕或其他進行中的 UI 工作。

可重現工具：原帖角色分層與離線比對（本機研究資料，未公開：`tools/audit_provenance_thread_roles.py`）。26 項離線測試通過；備份與驗證：交付檢查（本機研究資料，未公開：`docs/asset_provenance/later_archive_trace_20261004/delivery_validation.json`）。沒有 commit、push、對外聯絡或公開發布。

後續應優先復原具體日期的原帖／較晚製作日誌與合集；若取得公開連結或使用者保存的後續 ZIP，再做封包完整比對。新 uploader 候選必須先確認角色與作者連結，不能直接接到既有匿名作者身分。
