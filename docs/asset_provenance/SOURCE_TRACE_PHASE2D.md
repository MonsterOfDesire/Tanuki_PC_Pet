## Root visual-design author identified

Deon's [first-party X post](https://x.com/deon_Jetaime/status/1394789901392957443) contains the caption `ションボリルドルフ` and was published on 2021-05-19 (X snowflake: 2021-05-18 23:00:01 UTC). The attached illustration establishes the familiar rounded head/body, downcast horizontal eyes, pink cheeks, simplified paws, ears, and tail.

A [Futaba thread archived on 2021-05-31](https://tsumanne.net/si/data/2021/05/31/7320721/) already shows a pixel Shonbori/Tanuki version and calls the underlying picture the work of someone outside Futaba. A later [community discussion](https://umabbs.com/patio.cgi?log=past&pg=100&read=4373&res=187) independently names Deon and links the same first-party post as the first illustration.

The two exact 2021 attachment URLs were also checked through Internet Archive's availability endpoint. Neither had a saved snapshot; the search cache preserves only the thread text and file names. Therefore those attachments are recorded as **not retrievable**, not as visual non-matches.

Representative local files from all five character folders and both base/transformed forms were visually reviewed. They retain those defining design features. This supports a high-confidence link for the shared **ecosystem visual-design layer**, not a claim that Deon made the 456 GIFs.

Still unresolved: pixel conversion, base-body templates, character redraws, animation, expression variants, and later transformations/editing.

## Early animation branch remains anonymous

The [community history](https://w.atwiki.jp/niconicomugen/pages/11090.html) records that an anonymous Futaba volunteer next made a low-frame flailing animation, followed by multiple motions traced from the *Himouto! Umaru-chan* meeting scene. The early [NicoNico copy sm38852466](https://www.nicovideo.jp/watch/sm38852466), posted 2021-06-07, explicitly labels Futaba as its repost source; its uploader is therefore not credited as animator. The later [sm39422705](https://www.nicovideo.jp/watch/sm39422705), posted 2021-10-02, says the material set was already complete, so it is also downstream-use evidence.

The same history describes external export as historically disfavoured and later mass diffusion as tacitly tolerated. That community norm is neither an individual creator licence nor proof that a specific local GIF is prohibited. No local action group is linked to these animations until source frames can be recovered and compared.

## Permission finding

The screened X profile, focused first-party policy search, and official site did not expose terms granting app embedding or original-file redistribution. Absence of a prohibition is not permission. Deon's [official contact form](https://deon3.com/) is a viable inquiry route; no message was sent.

Cygames' [current derivative-work guideline](https://umamusume.jp/derivativework_guidelines) separately requires respect for third-party rights and excludes commercial use beyond doujin activities. It does not grant permission to redistribute another fan creator's files in an app or installer.
